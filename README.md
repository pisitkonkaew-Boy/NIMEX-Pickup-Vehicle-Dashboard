# NIMEX Pickup Vehicle Dashboard

หน้าเว็บรายงานรถเข้ารับสินค้า (BKK 3 DC: 610, 621, 691) อ่านข้อมูลจาก Google Sheet ผ่าน Apps Script

- ไม่มีตัวเลขใน repo นี้ ข้อมูลทั้งหมดอยู่ใน Google Sheet ห้ามนำไฟล์รายงาน NIMEX016267 หรือไฟล์ HTML ที่ฝังข้อมูลขึ้น repo
- repo นี้เป็นสาธารณะ ใครก็เห็นโค้ดได้ และถ้าเปิดลิงก์เว็บให้ทุกคน ข้อมูลก็เปิดตามนั้น
- ผู้ชมทั่วไปเปิดลิงก์ตามปกติ ผู้ดูแลเปิดด้วย `#admin` ต่อท้ายลิงก์แล้วใส่รหัส
- รหัสผู้ดูแลเก็บใน Script Properties ชื่อ `ADMIN_KEY` ของ Apps Script เท่านั้น
- ผู้ดูแลเติมข้อมูลเดือนใหม่จากเมนู ⋯ → อัปโหลดไฟล์ใหม่ ระบบแสดงสรุปให้ตรวจก่อนบันทึก วันที่ซ้ำจะลบของเดิมแล้วยึดค่าใหม่
- การตั้งค่าในหน้าตั้งค่า (คอลัมน์ตาราง DC, ลูกค้าที่ยกเว้น, เวลาตัด) บันทึกลง Sheet ผู้ชมทุกคนเห็นค่าเดียวกัน
- ที่อยู่ระบบข้อมูลตั้งไว้ใน `config.js` เมื่อแก้หน้าเว็บให้เพิ่มเลข `PICKUP_V` เพื่อล้างแคช
- โค้ดฝั่ง Apps Script อยู่ใน `Code.gs.txt`
- ปุ่มแชร์/ส่งออกอยู่ใน `share.js` (โหลดก่อน `app.js`) ใช้ฟังก์ชันคำนวณเดิมจาก `app.js` ทั้งหมด ไม่คำนวณ KPI ใหม่
  - เลือกหัวข้อได้ + ดีสุด/แย่สุดรายตัวชี้วัด (Ontime %, Delay %, ล่าช้าเฉลี่ย, รายได้, ชิ้น/คัน) จัดอันดับราย DC และรายทะเบียน (ทะเบียน ≥5 เที่ยว)
  - อินโฟกราฟิก 16:9: SVG 1920×1080 → PNG 3840×2160 (การ์ด 8 ใบ + กราฟ 4 ด้าน)
  - เกรด A–F (Ontime %: A≥95 B≥90 C≥85 D≥80 · Delay %: A≤5 B≤10 C≤15 D≤20) ปิดไว้เป็นค่าเริ่มต้น เปิดได้ที่หน้าต่างแชร์ → "แสดงเกรด A–F" (บันทึกลง Sheet ชื่อ `showGrade`)
- [16/11/2569] ปุ่ม **แผนเดิม / แผนใหม่** มุมขวาบน (จำค่าในเบราว์เซอร์)
  - แผนใหม่วัดเฉพาะสินค้าแห้ง (AB) ของลูกค้าในแผน (แท็บ `Plan` ใน Google Sheet) · กลุ่มทัน Cut off ตัดตามเวลา DC · กลุ่มตก Cut off ตัด 20:00
  - 1 เที่ยวอยู่กลุ่มทันถ้ามีลูกค้ากลุ่มทันอย่างน้อย 1 ราย · เที่ยวที่ไม่มีเวลากลับ = Delay · ช่อง AB/CC ทุกจุดแสดงเป็น กลุ่มทัน/กลุ่มตก
  - เพิ่ม 3 กรอบ: ลูกค้าในแผนที่เข้ารับ · บิล · กล่อง (แยกกลุ่ม)
  - ตั้งค่า → แผนลูกค้า: นำเข้า Excel / เพิ่ม / ลบ / ดาวน์โหลด และรายชื่อลูกค้าสินค้าแห้งนอกแผน (ยังไม่นับ)
  - ต้อง Deploy `Code.gs.txt` ใหม่ (มี action `plan` และแท็บ `Plan`)
